# Awesome-AI-for-VFX
A curated collection of research papers, tools, workflows, and repositories for machine learning in visual effects, with a focus on compositing.

## Roto/Prep

Used in productions. Great to generate masks for all kinds of things. For temping shots these can be great. Somtimes can replace manual rotoscoping.
